# ai-boilerplate-chrome-extension

A lightweight Chrome extension starter built with Manifest V3, Vite, and TypeScript.
Use Node.js 20+ and npm 10.9+ from this directory.

The template includes the common extension entry points:

- `public/manifest.json`: Manifest V3 configuration.
- `src/background.ts`: extension service worker.
- `src/extension-messages.ts`: typed runtime message helpers shared by the service worker.
- `src/popup/main.ts`: popup page logic and active-tab inspection.
- `src/popup/tabs.ts`: URL checks that keep browser-internal pages out of the inspection flow.
- `popup.html`: extension action popup page.

## Project Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Vite serves the popup page for regular UI development. For extension API testing, build the extension and load the `dist` directory in Chrome.

## Verification And Build

```bash
npm run type-check
npm test
npm run build
```

The build output is generated in `dist`.

Run `npm run type-check && npm test` as the routine verification command before
loading or packaging the extension. The tests cover runtime message parsing and
tab URL filtering, which are the core safety checks for the popup and service
worker flow. Run `npm run build` when checking the final Vite bundle or
creating a package.

Manifest permission changes are user-visible and affect Chrome Web Store
review. When adding or removing a permission, record why the feature needs it,
run `npm run type-check && npm test`, then run `npm run build` and load the
generated `dist` directory for a manual extension smoke check.

## Load in Chrome

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select the `dist` directory generated by `npm run build`.
5. Open any `http` or `https` page, then click the extension icon to test active-tab inspection from the popup.

Browser-internal pages such as `chrome://extensions`, local files, and malformed
URLs are intentionally rejected by the popup inspection flow.

## Package

```bash
npm run pack:zip
```

This creates `chrome-extension.zip` from the built `dist` directory.

## Customize

- Update `name`, `description`, and `version` in `public/manifest.json`.
- Update `name` in `package.json`.
- Add extension permissions only when a feature needs them.
- Keep content-script code isolated from the page DOM unless direct DOM access is required.
