# Upstream

- Repository: https://github.com/its-me-debk007/kotlin-android-mvvm-template
- License: MIT
- Upstream branch used: `main`
- Local package: `com.fzflabs.aiboilerplate.android`

## Selection Notes

Issue #5 asked for an Android template project selected from open source GitHub
projects and integrated into this repository.

The selected template is a lightweight GitHub template with Jetpack Compose,
MVVM, Hilt, Retrofit, Gradle Version Catalog, detekt, and a working sample API.
It fits this boilerplate repository better than larger sample applications
because it is small enough to act as a starting point while still including the
core Android app structure most projects need.

Other candidates reviewed:

- `cortinico/kotlin-android-template`: mature Kotlin Android template with a
  stronger library/template publishing focus.
- `android/nowinandroid`: official, comprehensive Android sample, but much
  larger and better suited as an architecture reference than a compact
  boilerplate starter.
